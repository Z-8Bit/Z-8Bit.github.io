CRC (Cyclic Redundancy Check)

CRC is a powerful error detection method widely used in digital networks and storage devices. It works by treating binary data as a polynomial and performing polynomial division using a generator polynomial.

Checksum

Checksum is a simple error detection method that works by summing blocks of data. The data is divided into fixed-size blocks, added together, and the one's complement becomes the checksum.

Hamming Code

Hamming Code is an error correction method that can detect and correct errors automatically. It places parity bits at power-of-2 positions within the data.
